Una colección de proyectos comunitarios construidos en CoderRupee.

:::note
¿Quieres agregar tu proyecto relacionado con CoderRupee a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-coderrupee](https://github.com/awesome-coderrupee/awesome-coderrupee) y [coderrupee.cafe](https://coderrupee.cafe), una comunidad que agrega el ecosistema y la comunidad.
