# CODER RUPEE — Production Candidate Brand Specification
Version: 1.0.0 | Status: Production-candidate assets generated; approval gates remain open

## Brand lockup
Product: CODER RUPEE
Endorsement: BY OPRAIZ
Tagline: ENGINEERING OPRAIZ INTELLIGENCE.

## Identity
Direction: A1 Architectural Interlock.
The CR monogram uses a 300 × 300 viewBox and 20-unit consistent stroke. The shared central vertical is the structural anchor; the C frame and R bowl/leg interlock around it. This is a custom vector construction and is not the OPRAIZ parent ring mark.

## Colour tokens
Deep Indigo #171A2E; Porcelain #F6F7F9; Coral Ember #FF765F; Aqua Teal #00BFA5; Muted Lavender #AEB3C7. Light theme uses contrast-adjusted Coral #E85F4B and Teal #008F7B.

## Typography
Inter for product and brand typography; JetBrains Mono for code and technical metadata. Confirm font licensing and bundle the selected font files in shipped products. SVG lockups use live text; convert text to paths only for final print/vendor handoff after font confirmation.

## Clear space and minimum use
Baseline clear space: at least one monogram stroke width around the symbol. Do not use the monogram below 24 px without optical-size testing. The 16 px favicon export is a technical convenience, not a guarantee of legibility.

## Required release gates — NOT represented as completed
1. Brand-owner visual approval of final geometry, wordmark spacing, colour values and all lockups.
2. Trademark clearance by qualified counsel/search provider in India, Malaysia and all intended commercial territories, including relevant software and technology classes.
3. Font and third-party asset licensing review.
4. WCAG 2.2 AA contrast testing across actual UI states, including hover, focus, disabled, error and selected states.
5. App-store/platform icon review on real Windows, macOS and Linux builds at actual sizes and backgrounds.
6. Confirm the product name and logo do not imply official OpenCode affiliation; preserve upstream notices and comply with the fork's license.
7. Sign-off of final exports and version pin in the release repository.

## Use restrictions
Do not alter OPRAIZ's parent logo or its ENGINEERING INTELLIGENCE tagline. Coder Rupee remains an independently identifiable product endorsed by OPRAIZ. Avoid unsubstantiated AI autonomy claims.
